# AutoMod AI — project screenshots

Screenshots to capture for the project report / demo documentation.
Drop the PNGs in this folder using the file names below (the user adds
these manually; nothing here is generated).

## Suggested capture setup

- Start everything with `npm run start:all` from the repo root.
- Use the **Toyota Corolla Altis** (the main demo car) signed in on the
  demo account, browser at ~1440×900, light theme as-is.
- Engine results take ~1–2 minutes per edit on Apple Silicon — capture
  the Studio shots from already-saved builds where possible.
